# 家計とカード Phase 1

iPhoneから使う家計管理のレビュー版です。既存サイトのコードと保存データには手を加えず、`refresh/` に独立したアプリを置いています。

```powershell
cd refresh
pnpm install --frozen-lockfile
pnpm dev
```

表示されたURLの `/refresh/` を開きます。初期設定ファイルは個別に配布します。開始月を選択して「その他」→「設定とバックアップ」から読み込むか、予算画面で入力してください。レビュー時はテストデータを使ってください。

端末内保存で、別のiPhoneとは同期しません。設定からCSV、JSON保存、JSON復元を利用できます。旧一括バックアップの月別家計は、設定から参照用に保存できます。新しい残高や支出には加算しません。支出は1回の買い物に複数の明細・カテゴリーを登録でき、割引後の合計がカードの引落予定に入ります。カード会社の請求額を入れると、記録との差額を確認できます。

本番ビルドをHTTPSの `/refresh/` に置くと、iPhoneのSafariからホーム画面に追加できます。最初にオンラインで開くとアプリの表示用ファイルを保存し、次回から通信がなくても端末内の記録を使えます。開発サーバーではオフライン準備を行いません。旧明細の取込、画像添付、共同利用、AIは後続です。

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

調査・移行・技術選定・ロードマップは [設計と移行](./設計と移行.md) を参照してください。
